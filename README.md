📁 Isi Repositori
 
-  htdocs.zip  — Paket utama kode sumber aplikasi 

- Cuplikan layar — Tampilan sistem 

-  ird.jpg  — Logo/gambar pendukung 
 
 
 
✨ Fitur Utama
 
✅ Halaman depan & Login Admin 
✅ Kelola Data Buku (Tambah/Ubah/Hapus/Lihat) 
✅ Kelola Data Anggota/Pengguna 
✅ Transaksi Peminjaman & Pengembalian 
✅ Riwayat Transaksi Lengkap 
✅ Tampilan menu samping & nuansa ungu 
 
 
 
⚙️ Persyaratan Sistem
 
- Web Server: XAMPP/Apache (dengan dukungan PHP)

- PHP 7.4+

- MySQL / MariaDB
 
 
 
🚀 Cara Pemasangan
 
1. Unduh / Clone repositori ini

2. Ekstrak  htdocs.zip  ke dalam folder  htdocs  atau direktori server lokal 

3. Buat database baru di MySQL

4. Sesuaikan berkas  koneksi.php  dengan pengaturan basis data kamu

5. Akses melalui peramban web
